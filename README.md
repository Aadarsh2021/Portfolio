## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/Aadarsh2021/Portfolio.git
cd Portfolio

# 2. Install dependencies
npm install

# 3. Start development server
npm start
```

### Production Build & Deployment

```bash
# Build optimized bundle
npm run build

# Deploy to Firebase Hosting
npm run deploy
```
